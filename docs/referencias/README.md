# Referências salvas

Coloque aqui capturas e textos das fontes históricas do Café Mania que o ambiente de desenvolvimento não consegue abrir (ver `docs/REFERENCE_AUDIT.md`).

- Um arquivo por fonte: `AAAA-MM-DD_<site>_<assunto>.<png|pdf|txt|md>`.
- Inclua a URL de origem e a data da captura.
- Estes arquivos são material de consulta: a arte do jogo continua original, desenhada para o projeto; não recorte sprites destas capturas.
